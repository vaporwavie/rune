- **`SplitView::sidebar_title` puts an app's mark or name in the sidebar's title bar row**, past the traffic lights and before an in-header toggle, moving with the sidebar's spring. It shrinks before the toggle does, so a long name truncates, and the row still drags the window. `shell::INSET`, the 8 points rows sit in from the sidebar's sides, is now public so a title can line up with the rows.
